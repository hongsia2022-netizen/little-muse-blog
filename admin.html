GitHub에 발행

이 화면은 누구나 열 수 있지만, 저장소 쓰기 권한이 있는 본인만 발행할 수 있어요. 토큰은 서버나 브라우저 저장소에 보관하지 않으며 GitHub API로만 전송돼요.

GitHub 발행용 토큰 만들기 ↗

Fine-grained token → Repository access에서 little-muse-blog만 선택 → Repository permissions의 Contents를 Read and write로 설정하세요. 만료되면 새 토큰을 만들면 돼요. 토큰을 채팅이나 게시물에 붙이지 마세요.

발행 후 공개 사이트에 반영되기까지 몇 분 걸릴 수 있어요. 공개 저장소이므로 발행한 글·이미지와 이전 버전은 공개됩니다.
